# Changelog — Hellsaiz PC AI

Все значимые изменения проекта. Формат: версия — что изменилось для человека.

## 0.3.0 — запуск без UAC

- Приложение и лаунчер больше не требуют прав администратора при обычном запуске:
  двойной клик по ярлыку открывает окно сразу, без запроса UAC.
- Модель Wolf-Girl активна, персона сохраняется в `personas.json`.

## 0.2.9 — модели компаньона и персона

- Импорт PNGTuber-паков (ZIP): валидация (только PNG + model.json/README, лимит 200 МБ,
  защита от path-traversal), распаковка в `companion_models/<slug>`, недостающие кадры
  деградируют (нет blink/talking — ок, нет idle — отказ).
- Реестр моделей и переключение живьём: выбор модели в «Настройки → Оформление» рядом
  с переключателем компаньона, активная модель запоминается.
- Персона ассистента: окно с именем, характером (5 пресетов), длиной/стилем ответов,
  голосом и моделью; промпт собирается строгим шаблоном с эскейпингом полей.
- Импортирована модель Wolf-Girl (idle/talking/blink/blink-talking), проверено
  отображение кадров.

## 0.2.7 — музыка и хром

- Плеер: обложка на каждой песне, пульс по доминирующему цвету обложки (только плашка,
  не фон), кнопка «Открыть» убрана — открывает нажатие на обложку, кнопки плеера крупнее.
- Текст карточки больше не мигает между треком и служебными названиями плеера.
- Чат: ряд пилюль «ИИ · STT · TTS» под композером, как в референсе.
- Окно: скруглённые углы под шапку, кнопки окна крупнее.
- Быстрые команды: полностью скруглённые кнопки.

## 0.2.6 — стабильный запуск

- Второй запуск больше не показывает тупиковое окно: он поднимает уже открытое окно
  и тихо завершается (локальный сокет рядом с файловым замком).
- Сборка несёт `PySide6.QtNetwork` для этого механизма.

## 0.2.3 — плеер и проверка

- Медиа-сессия читается в отдельном потоке с инициализацией COM-квартиры WinRT,
  `winrt` включён в сборку, добавлен резервный опрос из главного потока.
- Плеер в собранной версии: трек, исполнитель, состояние и обложка из Яндекс Музыки.

## 0.2.1 — полировка интерфейса

- Чат: микро-взаимодействия — фокус композера, подсветка копирования, hover/press кнопок
  отправки и микрофона, аккуратная плашка «новые сообщения».
- Настройки: табы-пилюли в общем стиле, панели-секции со скруглением, больше воздуха.
- Кнопка «ИИ» в шапке чата больше не выходит за границы строки (проверено аудитом HUD:
  было 2 замечания, осталось 0 по нашим виджетам).
- Добавлены документы: `docs/REFERENCE_KNICE.md` (разбор knice.tech) и
  `docs/ROADMAP_IDEAS.md` (список будущих функций).

## 0.2.0

### Интерфейс
- Безрамочное окно: свой заголовок, кнопки свернуть/развернуть/закрыть, перетаскивание
  и изменение размера за края.
- Чат: переключатель «ИИ / Локально» и локальная база разговора (~90 фраз, 100+ ответов).
- Плеер: настоящий трек, исполнитель и обложка из Windows Media Session (Яндекс Музыка).
- Vosk: исправлена проверка модели и добавлены зеркала загрузки; распознавание проверено.
- Полностью новый главный экран: карточки на спокойных тёмных поверхностях, мягкая тень,
  скругления, адаптивная сетка 1/2/3 колонки. Карточки больше не сжимаются и не наезжают
  друг на друга. Главный экран умещается целиком, без прокрутки: погода (с чипами прогноза),
  музыка, быстрые команды, система и последний ответ.
- Чат: широкая колонка (до 900 px), пузырь пользователя прижат вправо, ассистента —
  влево, у пузырей единое скругление 16 px. Верхняя плашка с аватаром и статусом убрана —
  осталась только кнопка очистки истории. Композер — капсула, подсказки внизу не обрезаются.
- Пустой чат: крупный заголовок «Хеллсайз» чуть выше середины, как заголовок страницы.
- Приветствие на главной теперь с именем владельца: «Добрый вечер, Хеллсайз».
- «Распознано:» больше не дублируется в голосовых сообщениях.
- Убраны чёрные полосы у рядов переключателей и секций в «Настройках» — фон теперь
  принадлежит окну, а не каждому вложенному виджету.
- Иконки интерфейса — Lucide (27 штук), единый набор, без эмодзи-глифов; в сборке
  иконки поставляются вместе с приложением.
- Карточка погоды: город отдельной строкой, число не пересекается с деталями,
  три дня прогноза, служебная строка «Обновлено ЧЧ:ММ».
- Напоминания переехали на свою страницу — с главного экрана карточка убрана по просьбе
  владельца.
- Пустые состояния («Голосов пока нет») вместо пустых чёрных прямоугольников.

### Функции
- Сценарии в общем стиле: карточки-секции со скруглением, крупный заголовок страницы,
  панель библиотеки с пустым состоянием («Сценариев пока нет…»), аккуратные табы-пилюли.
- Сценарии: в пустом «Действия сценария» — кнопка «Добавить действие» и подсказка;
  «Запустить» неактивна без действий и без сохранённого сценария, рядом — статус;
  «Удалить выбранный» неактивна без выделения.
- Погода: последний успешный прогноз кешируется на диск, без сети показываются
  сохранённые данные с подписью «Нет соединения — показаны сохранённые данные».
- Компаньон: по умолчанию появляется в правом нижнем углу и не перекрывает интерфейс;
  позиция, масштаб и видимость сохраняются между запусками.
- Настройки: битый `config.toml` больше не мешает запуску — приложение стартует
  на значениях по умолчанию и пишет предупреждение в лог.

### Исправлено
- Приложение закрывается по крестику: WM_CLOSE завершает процесс (проверено 3 цикла).
- Путь к модели Vosk показывается один раз, полный путь — в подсказке.
- Системные голоса Windows: вместо технической английской ошибки с командой `pip` —
  человеческий текст, причина в лог.
- Тексты: дневное приветствие больше не говорит «Вечер», убран дубль «Вечер» на главной,
  подсказка про голос Дениса ведёт «из списка», а не «ниже».

### Известное
- Персонаж компаньона — временная заглушка (финальную модель готовит владелец).
- Музыкальная карточка управляет системными медиа-клавишами и показывает состояние,
  но не название трека (нужен системный медиа-API).
- Сложные сценарии (условия и ветки) редактируются только в режиме «Для разработчиков».
- Локальные тесты `test_updater_package_smoke` и `test_vosk_model_library` падают
  в окружении без `cryptography` и без прав на симлинки; на CI с extras — зелёные.
