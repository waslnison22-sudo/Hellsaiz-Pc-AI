# Changelog — Hellsaiz PC AI

Все значимые изменения проекта. Формат: версия — что изменилось для человека.

## 0.2.0 (в подготовке)

### Интерфейс
- Полностью новый главный экран: карточки на спокойных тёмных поверхностях, мягкая тень,
  скругления, адаптивная сетка 1/2/3 колонки. Карточки больше не сжимаются и не наезжают
  друг на друга — сетка прокручивается.
- Чат: колонка сообщений фиксированной ширины (до 680 px), пузырь пользователя прижат
  вправо, ассистента — влево, у пузырей единое скругление 16 px. Композер — капсула,
  без чёрных полос вокруг кнопок.
- «Распознано:» больше не дублируется в голосовых сообщениях.
- Убраны чёрные полосы у рядов переключателей и секций в «Настройках» — фон теперь
  принадлежит окну, а не каждому вложенному виджету.
- Иконки интерфейса — Lucide (27 штук), единый набор, без эмодзи-глифов; в сборке
  иконки поставляются вместе с приложением.
- Карточка погоды: город отдельной строкой, число не пересекается с деталями,
  три дня прогноза, служебная строка «Обновлено ЧЧ:ММ».
- Пустые состояния («Голосов пока нет», «Активных напоминаний нет») вместо пустых
  чёрных прямоугольников.

### Функции
- Сценарии: в пустом «Действия сценария» — кнопка «Добавить действие» и подсказка;
  «Запустить» неактивна без действий и без сохранённого сценария, рядом — статус;
  «Удалить выбранный» неактивна без выделения.
- Погода: последний успешный прогноз кешируется на диск, без сети показываются
  сохранённые данные с подписью «Нет соединения — показаны сохранённые данные».
- Компаньон: по умолчанию появляется в правом нижнем углу и не перекрывает интерфейс;
  позиция, масштаб и видимость сохраняются между запусками.
- Настройки: битый `config.toml` больше не мешает запуску — приложение стартует
  на значениях по умолчанию и пишет предупреждение в лог.

### Исправлено
- Приложение закрывается по крестику: WM_CLOSE завершает процесс (проверено 3 цикла).
- Путь к модели Vosk показывается один раз, полный путь — в подсказке.
- Системные голоса Windows: вместо технической английской ошибки с командой `pip` —
  человеческий текст, причина в лог.
- Тексты: дневное приветствие больше не говорит «Вечер», убран дубль «Вечер» на главной,
  подсказка про голос Дениса ведёт «из списка», а не «ниже».

### Известное
- Персонаж компаньона — временная заглушка (финальную модель готовит владелец).
- Музыкальная карточка управляет системными медиа-клавишами и показывает состояние,
  но не название трека (нужен системный медиа-API).
- Сложные сценарии (условия и ветки) редактируются только в режиме «Для разработчиков».
- Локальные тесты `test_updater_package_smoke` и `test_vosk_model_library` падают
  в окружении без `cryptography` и без прав на симлинки; на CI с extras — зелёные.
