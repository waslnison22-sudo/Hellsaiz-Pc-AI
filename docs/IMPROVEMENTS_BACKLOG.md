## Волна 1 (ближайшая)

1. **Относительная громкость** («сделай потише на 10», «погромче») — нужен tool чтения текущей громкости (ctypes `IAudioEndpointVolume`) и кэш состояния; ключ настроек `volume_step` из issue #18.
2. **Barge-in вживую** — при новом вводе вызывать `SpeechOutputRouter.stop()` (issue #18, п. 2).
3. **Настройки** — все 8 пунктов из issue #18 (chatGPT; правки desktop.py).
4. **ci.yml paths-ignore** — не гонять 4 матричные джобы на docs-коммитах (файл `hellsaiz/ci_yml_with_paths_ignore.yml` готов; применить, когда появится доступ к `.github/workflows/`).
5. **Управление медиа голосом** — play/pause/next/prev через SendInput VK_MEDIA_* клавиши: просто, безопасно, очень востребовано. Новый tool `media_key` + команды «включи музыку дальше» и т. п.
6. Удалить пустую ветку `feat/commands-variants-01` (создана от main по ошибке).
