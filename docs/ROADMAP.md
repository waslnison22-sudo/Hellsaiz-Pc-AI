# Дорожная карта Hellsaiz PC AI — 0.1.4 → 0.2

Составлено 15.11.2026 по приоритетам владельца.

## 1. Приоритеты владельца

1. Стабильность и «укрепление» приложения, быстрый отклик.
2. Худ: чёрный стиль, глассморфизм, смена обоев, плавные анимации.
3. Голос: лучше озвучка (TTS), лучше распознавание (STT), лучше приём команд.
4. Команды: больше, умнее, без лишних подтверждений; живое общение без ИИ с вариантами ответов.
5. Компаньон на рабочем столе (0.2+), с установкой скинов/моделей из интернета.
6. Варианты ИИ (несколько провайдеров на выбор).
7. Быстрый запуск приложений, работа в фоне.
8. Установщик; запуск только от администратора.

## 2. Разбиение по волнам

| Волна | Содержание | Исполнитель | Целевая версия |
|---|---|---|---|
| A. Фундамент | Завершить этап 1 рефакторинга, влить WorkflowStudio, стабилизировать | Алиса + chatGPT | 0.1.4 |
| B. Худ и интерфейс | Разбор main() на страницы, глассморфизм, обои, анимации, человеческие тексты | chatGPT (UI) + Алиса (структура) | 0.1.5 |
| C. Скорость | Lazy-импорты, профилирование запуска, трей/фон, мгновенный отклик | Copilot | 0.1.5 |
| D. Голос и команды | TTS/STT качество, расширение команд, варианты ответов без ИИ, политика подтверждений | Copilot + chatGPT (UI) | 0.1.6 |
| E. Компаньон и ИИ | Провайдеры ИИ как опции, каркас компаньона, каталог скинов | chatGPT (UI/каркас) + Copilot | 0.2 |
| F. Дистрибуция | Установщик, admin-only, автообновление | Copilot | 0.1.6+ |

Правило: каждая волна — отдельные ветки/PR по конвенции из `docs/REFACTORING_PLAN.md`.
Этап 2 (вынос страниц из main()) — обязательный prerequisite для волн B и E, иначе
весь новый UI попадёт обратно в монолит.

## 3. Задания для chatGPT (Codex)

Общие правила: работать в ветке от свежего `dev/bootstrap` после слияния PR #4 (этап 1)
и применения патча правки `desktop.py`; перед записью сверять ветку и обновлять только по
ожидаемому SHA; не менять поведение; тексты пользователю — на русском, идентификаторы — на
английском; `pytest -q` зелёный, `tests/test_desktop_runtime.py` и `tests/test_theme.py`
не сломаны; читать `docs/HUD_AND_UPDATES.md` и `docs/ENGINEERING_NOTES.md` перед изменением UI.

- **CH-1. Интеграция WorkflowStudio в «Сценарии»** — режим «собрать из блоков» по умолчанию,
  JSON-редактор в режиме «Для разработчиков»; подписи блоков через `describe_action`/
  `describe_trigger`; сохранять блок «повтор» как единый элемент.
- **CH-2. Худ: чёрный глассморфизм + смена обоев** — токены стиля вместо магических rgba;
  страница «Обои» с предпросмотром; фикс обрезанных подписей кнопок «Сценариев»; группировка
  списка «Приложения»; человеческий раздел «Обновления» в настройках.
- **CH-3. Каркас компаньона (0.2)** — `app/companion/` с CompanionWindow (frameless,
  always-on-top, прозрачный); формат скина manifest.json + спрайты (док `COMPANION_SKINS.md`);
  в desktop.py не встраивать до этапа 2.
- **CH-4. Выбор ИИ-провайдера в настройках** — секция «ИИ»: провайдер, ключ/адрес, тест
  подключения; статус «ИИ выключен — локальный режим»; ключи только через secure store.

## 4. Задания для Copilot

Общие правила: маленькие самодостаточные PR; тесты обязательны; без новых зависимостей
без обсуждения; русские тексты для пользователя.

- **CO-1. Ускорение запуска** — профилирование (`python -X importtime`), lazy-импорты
  vosk/rapidocr/onnxruntime/piper/cv2/pywinauto; замер до/после зафиксировать в ENGINEERING_NOTES.
- **CO-2. Команды и варианты ответов без ИИ** — синонимы, fuzzy-совпадение, 2–4 варианта
  реплик на команду без повторов подряд; автогенерация `docs/COMMANDS.md` из registry.
- **CO-3. Политика доверия (команды без подтверждения)** — три уровня (всегда спрашивать /
  спрашивать только опасное / не спрашивать), слово-пароль для отключения, журнал команд.
  Список опасных инструментов фиксирован в коде.
- **CO-4. Озвучка (TTS)** — barge-in (прерывание речи новой командой), кэш синтеза частых
  фраз, предпрослушивание голосов.
- **CO-5. STT и приём команд** — VAD-отсечка тишины, грамматика команд для Vosk,
  настройка порога wake-слова, статусы в HUD.
- **CO-6. Трей и фон** — QSystemTrayIcon со статусами и меню; закрытие окна сворачивает
  в трей (настраиваемо).
- **CO-7. Установщик и admin-only** — проверка Inno Setup скрипта, проверка прав при старте,
  запуск через Task Scheduler с highest privileges; задокументировать риск admin-прав
  (политика CO-3 обязательна).

## 5. Что НЕ включать в 0.1.4

- Этап 2 рефакторинга (вынос страниц) — после стабильного тега.
- Полный редизайн худа — минимум: интеграция студии + фиксы обрезанных подписей.
- Компаньон — только каркас, не полноценная фича.
