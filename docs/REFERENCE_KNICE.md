# Разбор knice.tech (Astra) — что стоит перенять

Дата: 27.11.2026. Источник: https://knice.tech/ (живой макет и тексты страницы).

## Что у них есть

1. **Живой макет окна прямо на лендинге** — посетитель «пишет Астре», видит ответ, видит
   свой рабочий стол. Демо = продукт, а не скриншот.
2. **Рабочий стол как домашний экран**: приветствие по имени, «Последний чат», «Включить
   микрофон», «Какая погода?» — три быстрых входа, а не меню.
3. **Правая колонка со списком чатов** и группировкой по времени («только что», «2 ч назад»,
   «Вчера») — история как в мессенджере.
4. **Сегментированный переключатель режимов ответа**: `AI · STT · TTS` — видно, что включено.
5. **Карточки «как мы проведём день»**: погода + план, найденный файл, готовая команда,
   «просто поговорить». Каждая карточка показывает *результат*, а не описание функции.
6. **Команды = визуальный конструктор** с узлами (хоткей → открыть URL → условие → действие),
   группами («Продуктивность», «Фокус») и статусом запуска.
7. **Внешность персонажа настраивается** (модель, голос, имя, роль), модель можно выключить.
8. **Расширения: MCP-серверы, плагины, маркетплейс** — экосистемность.
9. **Телефон**: Telegram-бот уже сейчас, приложение Astra Connect в планах.

## Что берём в Hellsaiz (по приоритету)

| Идея | Что делаем у нас | Сложность |
|---|---|---|
| Переключатель режимов `AI · STT · TTS` рядом с чатом | уже есть «ИИ/Локально», добавить индикаторы STT и TTS | низкая |
| Список чатов с группировкой по времени | панель истории в чате; сейчас история хранится в SQLite | средняя |

| Карточки-результаты вместо описаний | «Последний ответ» уже так работает; расширить на сценарии | низкая |
| Конструктор команд с узлами и группами | у нас есть сценарии; добавить группы и статус запуска | средняя |
| Настройка имени/голоса персонажа | имя уже в конфиге, голоса в «Голоса»; свести в «Компаньон» | низкая |
| MCP/плагины | сильный ход, но это отдельный слой интеграций | высокая |

## Чего у них нет, а у нас есть

- Локальные ответы без интернета и ИИ (наша база разговора).
- Автозапуск через Планировщик Windows с уровнем HIGHEST.
- Полный офлайн-стек: Vosk, Piper, OCR, сценарии без облака.

## Вывод

Наш продукт ближе к «инструменту на каждый день», Astra — к «персонажу». Перенимаем
*подачу*: домашний экран с быстрыми входами, история чатов, индикаторы режимов,
карточки-результаты. Не копируем: у нас свой характер интерфейса и офлайн-ядро.
