# Список функций, которые можно внести

Составлено 27.11.2026 по итогам релиза 0.2.0 и разбора референса Astra (knice.tech).

## Ближайшее (1–2 итерации, высокая отдача)

1. **История чатов**: панель со списком диалогов, группировка «сегодня / вчера / раньше»,
   переименование и удаление. Данные уже в SQLite.
2. **Индикаторы режимов** `AI · STT · TTS` в шапке чата — видно, что включено, в один клик.
3. **«Продолжить чат»** на главной: карточка с последним диалогом и кнопкой вернуться.
4. **Голосовая кнопка на главной** («Включить микрофон») — сейчас микрофон только в чате.
5. **Группы сценариев** и статус запуска прямо в библиотеке.
6. **Имя и характер компаньона** в настройках (одна страница: имя, голос, модель, режим).
7. **Лаунчер: автозапуск по умолчанию** — предлагать включить при первом запуске.

## Средний срок

8. **Редактор команд с узлами** (хоткей → действие → условие), визуально, как в Astra.
9. **Горячие клавиши на сценарии** — редактор + индикатор занятых сочетаний.
10. **Плагины/MCP**: реестр инструментов, подключение внешних серверов, страница «Расширения».
11. **Маркетплейс сценариев**: экспорт/импорт `.json`, рейтинги, установка в один клик.
12. **Telegram-бот** как удалённый пульт (часть команд уже описана в сценариях).
13. **Календарь и задачи** вместо только напоминаний.
14. **Погода на несколько дней** в развёрнутой карточке (у нас 3 чипа — расширить).

## Дальше

15. **Мобильное приложение/веб-панель** для тех же команд (Astra Connect-аналог).
16. **Смена моделей ИИ на лету** с профилями качества/скорости и локальными моделями.
17. **Память о пользователе**: предпочтения, частые сценарии, автоподстановки.
18. **Темы оформления** (светлая, контрастная) и масштаб интерфейса 100–150%.
19. **Экспорт/импорт всех настроек** одним архивом.
20. **Телеметрия отказов локально** (журнал ошибок с кнопкой «отправить»).

## Технический долг

- Довести токенизацию остатков QSS (inline-цвета в `desktop.py`, `chat_style.py`).
- Единая шкала шрифтов и отступов (K8).
- Покрыть тестами чат-сценарии: длинные сообщения, вложения, очистка истории.
