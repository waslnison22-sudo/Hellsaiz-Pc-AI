# Hellsaiz PC AI 0.2.0 — что изменилось

Версия 0.2.0 — это большой интерфейсный релиз: главная переехала на спокойный
тёмный стиль (knice), чат получил современную компоновку, компаньон впервые
появился на экране, а сценарии и голоса стали понятнее для первого запуска.

## Новое

- **Новая главная страница.** Погода, музыка, напоминания, быстрые команды,
  загрузка системы и последний ответ собраны в карточки с мягкими тенями и
  скруглениями. Сетка адаптивная: на узком окне — одна колонка, на широком — три.
- **Компаньон на экране.** Отдельное прозрачное окно с персонажем: перетаскивается
  мышью, масштабируется колесом, прилипает к краям экрана и «засыпает», если его
  долго не трогать. По умолчанию появляется в правом нижнем углу и не перекрывает
  интерфейс.
- **Чат в стиле knice.** Пузыри с «рваными» углами, разделители дней, группировка
  по минутам, плавное появление сообщений и плавная прокрутка, кнопка «новые
  сообщения», капсульный композер с микрофоном.
- **Сценарии:** в пустом «Действия сценария» появилась кнопка «Добавить действие» и
  подсказка по библиотеке действий; кнопка «Запустить» неактивна, пока в сценарии
  нет действий, и рядом написано, чего не хватает.
- **Погода с офлайн-кэшем.** Последний успешный прогноз сохраняется на диск: без
  сети карточка показывает сохранённые данные с подписью «Нет соединения —
  показаны сохранённые данные» и строкой «Обновлено ЧЧ:ММ».
- **Голоса:** пустой список теперь объясняет, что делать («Голосов пока нет…»).
- **Иконки.** Эмодзи в карточках «Что я умею» заменены на 27 иконок Lucide из
  встроенного набора — они одинаково рисуются на любой системе.

## Исправлено

- Приложение снова корректно закрывается: после закрытия главного окна процесс
  завершается, компаньон не остаётся висеть в памяти.
- Крупная температура больше не наезжает на строку условий и деталей — при
  масштабах 125 % и 150 % карточка держит высоту по своему содержимому.
- У названия города в карточке погоды убран чёрный фон, город показан отдельной
  строкой под заголовком «Погода».
- Настройки больше не показывают путь к модели Vosk дважды.
- Системные голоса: вместо технической английской ошибки с командой `pip` —
  человеческая подпись, а причина уходит в лог.
- Тексты интерфейса приведены к одному обращению: убраны дубли («Добрый вечер» +
  «Вечер. Сделаем тише…»), исправлена дневная подсказка, которая называла день
  вечером.

## Известное

- **Персонаж — временная заглушка.** Финальную модель нарисует владелец/внешний
  подрядчик; система моделей (`custom`/`live2d`) уже готова её принять.
- **Обновления локально не проверены подписью.** Ключ подписи обновлений хранится
  в GitHub Actions, поэтому локальные сборки-превью не содержат подписанного
  манифеста — это относится только к механизму автообновления, не к самому
  приложению.
- **Музыкальная карточка минимальна:** состояние и кнопки «назад / пауза /
  следующий» отправляют системные медиа-клавиши Windows; название трека не
  показывается (для этого нужен системный медиа-API, его пока нет).
- **Сложные сценарии** (с условиями и ветками) по-прежнему редактируются только в
  режиме «Для разработчиков».
- **Локальные падения тестов окружения:** `test_updater_package_smoke` требует
  установленный `cryptography`, `test_vosk_model_library` — права на симлинки
  Windows. На CI (с полными extras) обе группы зелёные.
